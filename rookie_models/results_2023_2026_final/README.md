# 2023-2026 Rookie Model Comparison

This directory is the clean comparison output for the 2023, 2024, 2025 and 2026 draft classes.

- `rookie_results_YEAR.csv`: each class separated by year and ranked within QB/RB/WR/TE.
- `QB_2023_2026_ranked.csv`, `RB_...`, `WR_...`, `TE_...`: all four draft classes ranked together within position using the frozen prospect-model score.
- `all_players_2023_2026_by_percentile.csv`: all positions together using the leakage-safe position-normalized prospect-model percentile. Tied percentiles remain tied.

No model was retrained or reselected to create these files.
